# 修六和法教维基（LLM Wiki）

本维基以「LLM Wiki」模式维护，整理 **刘素云老师（修六和 / 慈云法语 / m.xiuliuhe.org）** 的佛学开示。原始资料在 `doc/`（仅能由同步工具更动），本目录 `wiki/` 是由 LLM 持续编写、互相链接的知识库。

## 三层架构

1. **原始资料** `doc/影音/` — 由 `wiki/tools/api_client.py` 从 m.xiuliuhe.org 公开 API 同步的逐集文稿（2 类别、33 相簿、约 200+ 集），不可手动更动。
2. **维基** `wiki/` — LLM 撰写的页面：类别、主题、开示（每相簿一页）、概念、问答。
3. **纲要** `AGENTS.md` + `wiki/SCHEMA.md` — 规范结构与工作流程。

- 浏览：用 Obsidian 开启本资料夹，看图谱（graph view）与双向链接。
